# DentalDX — โปรแกรมวิเคราะห์ข้อมูล Data Exchange สภาวะทันตสุขภาพเด็ก

[![Build Windows EXE](https://github.com/nchotenin-tech/DataExchange-Analytics/actions/workflows/build-windows.yml/badge.svg)](https://github.com/nchotenin-tech/DataExchange-Analytics/actions/workflows/build-windows.yml)

วิเคราะห์ข้อมูลตรวจฟันเด็กจาก HDC ออกมาเป็นตารางรายงานตามระเบียบ พร้อมกราฟ
สรุปประเด็นอัตโนมัติ และรายชื่อเด็กที่ต้องติดตามมาตรวจ
ไล่ดูได้ตั้งแต่ภาพรวมจังหวัด → รายอำเภอ → รายหน่วยบริการ

**ทำงานในเครื่องท่านทั้งหมด ไม่ส่งข้อมูลออกนอกเครื่อง ไม่ต้องต่ออินเทอร์เน็ต**

---

# 📥 คู่มือติดตั้งและใช้งาน (สำหรับผู้ใช้ทั่วไป)

ไม่ต้องติดตั้ง Python ไม่ต้องติดตั้งอะไรเพิ่ม ใช้เวลาทั้งหมดไม่เกิน 5 นาที

## ขั้นที่ 1 — ดาวน์โหลด

ไปที่ **[หน้า Releases](https://github.com/nchotenin-tech/DataExchange-Analytics/releases/latest)**
→ กดโหลดไฟล์ `DentalDX-vX.Y.Z-win64.zip`

## ขั้นที่ 2 — แตกไฟล์

คลิกขวาที่ไฟล์ zip → **Extract All...** → เลือกที่เก็บ เช่น `D:\DentalDX`

> ⚠️ ต้องแตกไฟล์ออกมาก่อน **ห้ามเปิด .exe จากในไฟล์ zip โดยตรง** เพราะโปรแกรม
> ต้องอ่านโฟลเดอร์ `data` และ `profiles` ที่อยู่ข้าง ๆ

จะได้โครงสร้างแบบนี้:

```
DentalDX\
├─ DentalDX.exe          ← ไฟล์โปรแกรม
├─ data\                 ← วางไฟล์ข้อมูลของท่านที่นี่
│   ├─ 6-12y\
│   └─ 0-5y\
├─ profiles\             ← เงื่อนไขการคำนวณของแต่ละกลุ่มอายุ
├─ reference\            ← ตารางอ้างอิงหน่วยบริการ
└─ คู่มือผู้ใช้.txt
```

## ขั้นที่ 3 — วางไฟล์ข้อมูล

นำไฟล์ `.xlsx` ที่ดาวน์โหลดจาก HDC มาวางในโฟลเดอร์ให้ตรงกลุ่มอายุ

| กลุ่มอายุ | วางไฟล์ที่ |
|---|---|
| เด็กวัยเรียน 6-12 ปี | `data\6-12y\` |
| เด็กก่อนวัยเรียน 0-5 ปี | `data\0-5y\` |

วางกี่ไฟล์ก็ได้ในโฟลเดอร์เดียวกัน โปรแกรมจะอ่านรวมกันให้ทั้งหมด
(เช่น แยกไฟล์ตามอำเภอหรือตามเดือน ก็วางรวมกันได้เลย)

## ขั้นที่ 4 — เปิดโปรแกรม

**ดับเบิลคลิก `DentalDX.exe`**

- จะมีหน้าต่างสีดำขึ้นมา (อย่าปิด — เป็นตัวโปรแกรม)
- เบราว์เซอร์จะเปิดขึ้นเองที่ `http://127.0.0.1:8765`
- ครั้งแรกใช้เวลาอ่านข้อมูลราว **20-30 วินาที** (ข้อมูล 60,000 แถว) ครั้งต่อไปไม่ถึง 1 วินาที
- **ปิดโปรแกรม** = ปิดหน้าต่างสีดำ

### ถ้า Windows ขึ้นเตือน "Windows protected your PC"

กด **More info** → **Run anyway**

เกิดขึ้นเพราะไฟล์ยังไม่ได้ซื้อใบรับรองดิจิทัล (Code Signing Certificate) ไม่ใช่ไวรัส
หากไม่มั่นใจ ตรวจสอบซอร์สโค้ดทั้งหมดได้ใน repo นี้

## ขั้นที่ 5 — เปลี่ยนข้อมูลภายหลัง

วางไฟล์ใหม่ทับในโฟลเดอร์ `data\` แล้วกดปุ่ม **↻ โหลดข้อมูลใหม่** ในเมนูซ้ายของโปรแกรม
(ไม่ต้องปิดเปิดโปรแกรมใหม่ — โปรแกรมตรวจจับไฟล์ที่เปลี่ยนเอง)

---

## ❓ ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| เบราว์เซอร์ไม่เปิดขึ้นเอง | เปิดเบราว์เซอร์แล้วพิมพ์ `http://127.0.0.1:8765` |
| ขึ้น `PORT 8765 IS ALREADY IN USE` | มีโปรแกรมเดิมค้างอยู่ ปิดหน้าต่างสีดำเดิมก่อน |
| เปลี่ยนไฟล์แล้วตัวเลขไม่เปลี่ยน | กดปุ่ม **↻ โหลดข้อมูลใหม่** |
| หน้าเว็บเป็นรุ่นเก่า | กด `Ctrl + Shift + R` (โปรแกรมจะขึ้นแถบสีส้มเตือนให้เองถ้าไม่ตรงรุ่น) |
| ขึ้นว่า "ไม่พบไฟล์ข้อมูลใน ..." | ยังไม่ได้วางไฟล์ `.xlsx` ในโฟลเดอร์ `data\<กลุ่มอายุ>\` |
| ตัวเลขไม่ตรงกับที่คาด | เปิดกล่อง 💡 **สรุปประเด็น** และดูเงื่อนไขใต้ชื่อตาราง จะบอกสูตรที่ใช้ |

## 🔐 ความปลอดภัยของข้อมูล

- โปรแกรมไม่เชื่อมต่ออินเทอร์เน็ต ไม่ส่งข้อมูลไปที่ใดทั้งสิ้น
- ข้อมูลอยู่ในโฟลเดอร์ `data\` ในเครื่องท่านเท่านั้น
- `http://127.0.0.1` คือเครื่องของท่านเอง เครื่องอื่นในเครือข่ายเข้าไม่ได้
- ไฟล์รายชื่อที่ส่งออกมีข้อมูลส่วนบุคคล ควรเก็บและส่งต่ออย่างระมัดระวัง

## ภาพรวมสิ่งที่โปรแกรมทำได้

- **ตารางรายงานตามระเบียบ** — 6-12 ปี: ตารางที่ 1-6 | 0-5 ปี: ตารางที่ 1, 2, 3, 7
- **สรุปประเด็นอัตโนมัติ** ทั้งภาพรวมและแยกรายอายุ ชี้ว่าอายุไหนควรเน้นและช่วงไหนควรแทรกแซงก่อน
- **กราฟแท่ง** เปิด/ปิดได้ในทุกตารางสถิติ
- **Drill-down** จังหวัด → อำเภอ → หน่วยบริการ พร้อมกราฟเทียบร้อยละการตรวจกับผลตรวจ
- **รายชื่อเด็กที่ต้องติดตาม** ทั้งกลุ่มที่ยังไม่ได้ตรวจ และกลุ่มที่ตรวจแล้วข้อมูลตกเกณฑ์ (ระบุสาเหตุ)
- **ส่งออก** ทุกตารางเป็น Excel/CSV หรือรวมทุกตารางในไฟล์เดียวแยกชีต
