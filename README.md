# DentalDX — โปรแกรมวิเคราะห์ข้อมูล Data Exchange สภาวะทันตสุขภาพเด็ก

แปลงไฟล์ Excel ที่ส่งออกจาก HDC (Data Exchange การตรวจฟัน) ให้เป็นรายงานตามแบบ
ตารางที่ 1-7 พร้อมรายชื่อเด็กที่ต้องติดตาม

ตั้งแต่เวอร์ชัน 2.10.0 เป็น **ไฟล์ HTML ไฟล์เดียว** เปิดด้วยเบราว์เซอร์ ไม่ต้องติดตั้ง
และไม่ถูก Windows SmartScreen บล็อกเหมือนไฟล์ `.exe`

---

# 📥 คู่มือติดตั้งและใช้งาน (สำหรับผู้ใช้ทั่วไป)

## ขั้นที่ 1 — ดาวน์โหลด

ไปที่หน้า **Releases** แล้วโหลด **`Dashboard-Exam-vX.Y.Z.zip`**
คลิกขวา → **Extract All** จะได้

```
Dashboard-Exam\
├─ DentalDX-Dashboard-vX.Y.Z.html   ← ดับเบิลคลิกเปิดด้วย Chrome หรือ Edge
├─ อ่านก่อนใช้งาน.txt
├─ profiles\                         แก้เกณฑ์คำนวณเองได้
└─ data\
   ├─ 0-5y\
   └─ 6-12y\
```

## ขั้นที่ 2 — ดาวน์โหลดข้อมูลจาก HDC แล้ววางให้ถูกโฟลเดอร์

ไฟล์ Data Exchange ที่โหลดจาก HDC **มีชื่อคล้ายกันมากจนแยกไม่ออกว่าเป็นรายงานไหน**
จึงต้องเปลี่ยนชื่อไฟล์ตามตารางนี้ก่อนวาง

### 📁 `data\0-5y\` — ต้องใช้ 2 ไฟล์

| รายงานใน HDC | ชื่อไฟล์ต้องมีคำว่า |
|---|---|
| `1.17.4 OHSP` ร้อยละเด็ก **0-2 ปี** ได้รับการตรวจสุขภาพช่องปาก เฉพาะเขตรับผิดชอบ (คน) (ใช้แบบความครอบคลุม) | **`0-2`** |
| `1.17.8 OHSP` ร้อยละเด็ก **3-5 ปี** ได้รับการตรวจสุขภาพช่องปาก เฉพาะเขตรับผิดชอบ (คน) (ใช้แบบความครอบคลุม) | **`3-5`** |

ตัวอย่างชื่อไฟล์ที่ใช้ได้:

```
data\0-5y\dataexchange ตรวจฟันเด็ก 0-2 ปี.xlsx
data\0-5y\dataexchange ตรวจฟันเด็ก 3-5 ปี.xlsx
```

> ⚠️ ถ้าชื่อไฟล์ไม่มี `0-2` หรือ `3-5` โปรแกรมจะแยกช่วงอายุไม่ได้
> (โปรแกรมดูจากชื่อไฟล์เพื่อสร้างคอลัมน์ `agegroup` เพราะในไฟล์ไม่มีข้อมูลนี้)

### 📁 `data\6-12y\` — ใช้ไฟล์เดียว

| รายงานใน HDC | ชื่อไฟล์ |
|---|---|
| `1.17.11 OHSP` ร้อยละเด็ก **6-12 ปี** ได้รับการตรวจสุขภาพช่องปาก เฉพาะเขตรับผิดชอบ (คน) (ใช้แบบความครอบคลุม) | ตั้งชื่ออะไรก็ได้ |

ในแต่ละโฟลเดอร์มีไฟล์ **`_วางไฟล์ที่นี่.txt`** เขียนคำแนะนำนี้ไว้ให้อีกครั้ง
เผื่อลืมตอนใช้งานจริง

## ขั้นที่ 3 — เปิดโปรแกรม

ดับเบิลคลิกไฟล์ `.html` → กดปุ่ม **เลือกโฟลเดอร์ข้อมูล** → เลือกโฟลเดอร์ `Dashboard-Exam`
(เบราว์เซอร์จะถามยืนยันการอ่านโฟลเดอร์ ให้กดอนุญาต)

ต้องใช้ **Chrome หรือ Edge** — Firefox ยังเลือกทั้งโฟลเดอร์ไม่ได้

<details><summary>วิธีใช้แบบเดิม (.exe) ซึ่งยังแจกเป็นทางสำรอง</summary>


**ดับเบิลคลิก `DentalDX.exe`**

- จะมีหน้าต่างสีดำขึ้นมา (อย่าปิด — เป็นตัวโปรแกรม)
- เบราว์เซอร์จะเปิดขึ้นเองที่ `http://127.0.0.1:8765`
- ครั้งแรกใช้เวลาอ่านข้อมูลราว **20-30 วินาที** (ข้อมูล 60,000 แถว) ครั้งต่อไปไม่ถึง 1 วินาที
- **ปิดโปรแกรม** = ปิดหน้าต่างสีดำ

### ถ้า Windows ขึ้นเตือน "Windows protected your PC"

กด **More info** → **Run anyway**

เกิดขึ้นเพราะไฟล์ยังไม่ได้ซื้อใบรับรองดิจิทัล (Code Signing Certificate) ไม่ใช่ไวรัส
หากไม่มั่นใจ ตรวจสอบซอร์สโค้ดทั้งหมดได้ใน repo นี้

</details>

## ขั้นที่ 4 — เปลี่ยนข้อมูลภายหลัง

วางไฟล์ใหม่ทับในโฟลเดอร์ `data\` แล้วกดปุ่ม **↻ โหลดข้อมูลใหม่** ในเมนูซ้ายของโปรแกรม
(ไม่ต้องปิดเปิดโปรแกรมใหม่ — โปรแกรมตรวจจับไฟล์ที่เปลี่ยนเอง)

---

## ❓ ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| เบราว์เซอร์ไม่เปิดขึ้นเอง | เปิดเบราว์เซอร์แล้วพิมพ์ `http://127.0.0.1:8765` |
| ขึ้น `PORT 8765 IS ALREADY IN USE` | มีโปรแกรมเดิมค้างอยู่ ปิดหน้าต่างสีดำเดิมก่อน |
| เปลี่ยนไฟล์แล้วตัวเลขไม่เปลี่ยน | กดปุ่ม **↻ โหลดข้อมูลใหม่** |
| หน้าเว็บเป็นรุ่นเก่า | กด `Ctrl + Shift + R` (โปรแกรมจะขึ้นแถบสีส้มเตือนให้เองถ้าไม่ตรงรุ่น) |
| ขึ้นว่า "ไม่พบไฟล์ข้อมูลใน ..." | ยังไม่ได้วางไฟล์ `.xlsx` ในโฟลเดอร์ `data\<กลุ่มอายุ>\` |
| ตัวเลขไม่ตรงกับที่คาด | เปิดกล่อง 💡 **สรุปประเด็น** และดูเงื่อนไขใต้ชื่อตาราง จะบอกสูตรที่ใช้ |

## 🔐 ความปลอดภัยของข้อมูล

หน้าโปรแกรม**ถูกล็อกไม่ให้เชื่อมต่ออินเทอร์เน็ต**ด้วย Content-Security-Policy
(`connect-src 'none'`) ใช้งานได้แม้ถอดสาย LAN

ข้อมูลรายบุคคลอยู่ใน**หน่วยความจำชั่วคราวเท่านั้น** ปิดแท็บแล้วหายทั้งหมด
ไม่มีการบันทึกลงเครื่อง เบราว์เซอร์จำไว้เฉพาะ**ตัวเลขสรุปของรายงานล่าสุด** กดล้างได้ทุกเมื่อ

**ไฟล์ที่มีข้อมูลส่วนบุคคล** — เก็บและส่งต่ออย่างระมัดระวัง

- ไฟล์ Excel ที่วางใน `data\` (มาจาก HDC มีเลข 13 หลัก ชื่อ ที่อยู่)
- ไฟล์จากปุ่ม **รายชื่อเด็ก…** (มีเลขบัตร ชื่อ ที่อยู่)

**ไฟล์ที่ไม่มีข้อมูลส่วนบุคคล**

- ไฟล์ `.html` และ `.zip` ที่แจกใน Releases
- ไฟล์จากปุ่ม **บันทึกรายงาน (Excel)** — มีแต่ตัวเลขสรุป
- สิ่งที่เบราว์เซอร์จำไว้

## ภาพรวมสิ่งที่โปรแกรมทำได้

- **ตารางรายงานตามระเบียบ** — 6-12 ปี: ตารางที่ 1-6 | 0-5 ปี: ตารางที่ 1, 2, 3, 7
- **สรุปประเด็นอัตโนมัติ** ทั้งภาพรวมและแยกรายอายุ ชี้ว่าอายุไหนควรเน้นและช่วงไหนควรแทรกแซงก่อน
- **กราฟแท่ง** เปิด/ปิดได้ในทุกตารางสถิติ
- **Drill-down** จังหวัด → อำเภอ → หน่วยบริการ พร้อมกราฟเทียบร้อยละการตรวจกับผลตรวจ
- **รายชื่อเด็กที่ต้องติดตาม** ทั้งกลุ่มที่ยังไม่ได้ตรวจ และกลุ่มที่ตรวจแล้วข้อมูลตกเกณฑ์
  (ระบุสาเหตุ + ระบายสีแดงเฉพาะช่องที่ทำให้ตกเกณฑ์)
- **คลิกตัวเลขในตารางรายงาน** ที่เป็นปัญหา (ฟันผุ ฟันถอน ปริทันต์ ความจำเป็นในการรักษา)
  เพื่อดึงรายชื่อเด็กพร้อมคอลัมน์สรุป "ปัญหาที่พบ / สิ่งที่ต้องทำ" แล้วส่งออก Excel ไปติดตามงานต่อ
- **ส่งออก** ทุกตารางเป็น Excel/CSV หรือรวมทุกตารางในไฟล์เดียวแยกชีต
- **แท็บสำรวจข้อมูล (EDA)** — ตรวจค่าผิดปกติ/ขัดแย้งกันเอง 13 กฎ, boxplot + ฮิสโทแกรมของจำนวนซี่ฟัน
  (คลิกดูกราฟขนาดใหญ่ และคลิกตัวเลข/แท่งกราฟเพื่อดูรายชื่อเด็กเบื้องหลังตัวเลขนั้นได้),
  ความถี่ตัวแปรหมวดหมู่ (แปลรหัสให้อ่านออก) และ heatmap เทียบรายอำเภอ
- **แท็บถาม-ตอบ** — พิมพ์ `caries free ของอายุ 3 ขวบ` แล้วได้ตัวเลขทันที ไม่ต้องไล่หาว่าอยู่ตารางไหน
  ใช้ได้ทันทีโดยไม่ต้องต่อ AI (มีตัวแปลคำถามในเครื่อง) · ต่อ AI ได้ถ้าต้องการถามแบบภาษาพูด
