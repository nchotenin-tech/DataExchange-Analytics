# แท็บ 💬 ถาม-ตอบ — ถามข้อมูลเป็นภาษาสนทนา

พิมพ์ว่า `caries free ของอายุ 3 ขวบ` แล้วได้ตัวเลขทันที
ไม่ต้องไล่หาว่าอยู่ตารางไหน แถวไหน

---

## โหมด "ไม่ใช้ AI" — ค่าเริ่มต้น ใช้ได้ทันที

ไม่ต้องตั้งค่าอะไร ไม่ต้องต่อเน็ต **ไม่มีข้อมูลออกจากเครื่องเลย**
โปรแกรมใช้ **ตัวแปลคำถามแบบคีย์เวิร์ด** ที่ติดมาในตัว

| พิมพ์ | ได้ |
|---|---|
| `caries free ของอายุ 3 ขวบ` | ร้อยละปราศจากฟันผุ อายุ 3 ปี |
| `เด็กสามขวบฟันดีกี่เปอร์เซ็นต์` | เลขไทยตัวหนังสือก็อ่านออก |
| `ปราศจากฟันผุ อ.เมือง` | ชื่ออำเภอไม่เต็มก็เดาให้ (เมือง → เมืองชัยภูมิ) |
| `ปราศจากฟันผุ 3-5 ปี รายอำเภอ` | ตารางเทียบรายอำเภอ เรียงมาก→น้อย |
| `อำเภอไหนปราศจากฟันผุน้อยที่สุด` | เรียงน้อย→มาก |
| `ค่าเฉลี่ยฟันผุถอนอุด อายุ 4 ปี` | ค่าเฉลี่ยจากตารางที่ 3 |
| `จำนวนที่ผ่านเกณฑ์คุณภาพ 0-2 ปี` | จากตารางที่ 1 |

**พิมพ์ชื่อกำกวมจะถามกลับ ไม่เดาเอง** เช่น `อ.บ้าน` → *"มีอำเภอที่ขึ้นต้นด้วย
'บ้าน' หลายแห่ง: บ้านเขว้า · บ้านแท่น — ช่วยพิมพ์ชื่อให้ครบหน่อยครับ"*
(ตอบเป็นภาพรวมเงียบ ๆ อันตรายกว่าการถามกลับ)

**ยังทำไม่ได้ในโหมดนี้** — คำถามที่เรียงประโยคอิสระ เช่น
"อยากทราบว่าเด็กเล็กแถวอำเภอเมืองฟันแย่กว่าที่อื่นไหม" หรือประโยคที่มีคำปฏิเสธ
("ไม่เอา 3 ขวบ เอา 5 ขวบ") — พวกนี้ต้องเปิด AI

ถ้าคนในหน่วยงานเรียกตัวชี้วัดด้วยคำอื่น เติมใน `ALIASES` ที่ `core/ask.py` ได้เอง

## ข้อมูลเด็กไม่ออกจากเครื่อง

นี่คือหัวใจของการออกแบบ — AI ทำหน้าที่ **"แปลคำถาม"** อย่างเดียว
**ไม่ได้** เป็นคนคำนวณ และไม่เคยเห็นข้อมูลรายบุคคล

```
ผู้ใช้พิมพ์คำถาม
      │
      ▼
[1] ส่งให้ AI = คำถาม + แคตตาล็อก (ชื่อกลุ่มอายุ ชื่อตาราง ชื่อตัวชี้วัด)
      │                            ← ไม่มีชื่อ ไม่มีเลขบัตร ไม่มีตัวเลข
      ▼
[2] AI ตอบกลับเป็น JSON:  {"table":"2","metric":"ปราศจากฟันผุ","rows":["3"]}
      │
      ▼
[3] DentalDX คำนวณเองในเครื่อง  ← ใช้ core/engine.py ตัวเดียวกับตารางรายงาน
      │
      ▼
[4] ส่งให้ AI = ตัวเลขสรุปอย่างเดียว {"base":2832,"count":2262,"pct":79.87}
      │                              ← เพื่อเรียบเรียงเป็นประโยคภาษาไทย
      ▼
คำตอบ + ปุ่มดู "ที่มาของตัวเลข"
```

สิ่งที่ออกจากเครื่องมีแค่ 3 อย่าง: **คำถามของผู้ใช้ · ชื่อคอลัมน์/ตัวชี้วัด ·
ตัวเลขสรุป** — เท่ากับที่พิมพ์อยู่ในรายงานราชการอยู่แล้ว

## เห็นก่อน แล้วค่อยกดยืนยัน

ไม่ต้องเชื่อคำอธิบายข้างบน — **ดูของจริงได้ทุกครั้ง** ก่อนที่อะไรจะออกจากเครื่อง
โปรแกรมจะหยุดแล้วโชว์ให้ดูว่า

- ส่งไปที่ URL อะไร ใช้โมเดลไหน กุญแจใบไหน (ปิดบังไว้ เห็นแค่หัวกับท้าย)
- ขนาดกี่ไบต์
- **ข้อความที่จะส่งทั้งก้อน ไม่ตัดทอน** (มีปุ่มจัดรูปแบบให้อ่านง่าย)

แล้วรอให้กด **[ยืนยันส่ง]** หรือ **[ยกเลิก]** — กดยกเลิกแล้วไม่มีอะไรออกไปเลย

เพราะก้อนที่ 2 (ตัวเลขสรุป) ต้องรู้ผลลัพธ์ก่อนถึงจะสร้างได้ จึงถามยืนยัน **2 ครั้ง**
ครั้งแรกตอนแปลคำถาม ครั้งที่สองตอนส่งตัวเลขไปเรียบเรียง
ถ้ากดยกเลิกครั้งที่สอง ยังได้คำตอบครบถ้วน แค่เป็นรูปแบบมาตรฐานแทนประโยคธรรมชาติ
— **ตัวเลขเท่ากันทุกประการ** เพราะคำนวณในเครื่องไปแล้ว

สิ่งที่โชว์คือ payload ก้อนเดียวกับที่ส่งจริง ไม่ใช่ตัวอย่างที่เขียนไว้ให้ดู
(โปรแกรมเก็บคำขอที่เตรียมไว้ไว้ในหน่วยความจำ พอกดยืนยันก็ส่ง**ก้อนนั้น**ออกไป
ไม่ได้สร้างใหม่) — smoke test ตรวจข้อนี้ให้ด้วย

ปิดการถามยืนยันได้ด้วย `confirm: false` ใน `ai.yaml` ถ้าใช้จนคุ้นแล้วรำคาญ

### ประวัติสิ่งที่ส่งออกไปแล้ว

ปุ่ม **📤 ประวัติสิ่งที่ส่งออกไปแล้ว** ในแท็บถาม-ตอบ แสดงทุกครั้งที่มีการส่งจริง
ในรอบการทำงานนี้ — เวลา ขั้นตอน ปลายทาง ขนาด และผลลัพธ์
(เก็บในหน่วยความจำเท่านั้น ปิดโปรแกรมแล้วหาย ไม่มีการเขียนลงไฟล์)

`tools/smoke_test.py` มีการตรวจข้อนี้ให้อัตโนมัติ (ข้อ "prompt ที่ส่งให้ AI
ไม่มีข้อมูลรายบุคคล") ถ้าวันไหนมีใครเผลอส่งข้อมูลดิบออกไป เทสต์จะไม่ผ่าน

> ถ้าหน่วยงานห้ามต่อเน็ตเลย → ตั้ง `provider: ollama` รันโมเดลในเครื่อง
> ไม่มีอะไรออกจากเครื่องเลยแม้แต่คำถาม

## ตัวเลขต้องตรงกับตารางรายงานเสมอ

ปัญหาใหญ่ที่สุดของการต่อ AI เข้ากับข้อมูลคือ **AI มั่วตัวเลข**
เราตัดปัญหานี้ทิ้งโดยไม่ให้ AI แตะตัวเลขเลย

`core/ask.py` เรียกใช้ `quality_mask()` / `apply_scope()` / `bool_mask()`
ชุดเดียวกับที่สร้างตารางรายงาน ตัวเลขจึงตรงกันโดยโครงสร้าง ไม่ใช่โดยบังเอิญ

smoke test ไล่เทียบ **ทุกช่องของทุกตารางในทุกกลุ่มอายุ** (386 ช่อง)
ว่าคำตอบจากแท็บถาม-ตอบเท่ากับตัวเลขในตารางเป๊ะ ๆ

ใต้คำตอบทุกครั้งจะมีบรรทัด **"ที่มาของตัวเลข"** บอกว่ามาจากตารางไหน
ตัวชี้วัดอะไร แถวไหน ขอบเขตไหน และเงื่อนไขการคำนวณคืออะไร — ผู้ใช้เปิดตาราง
ตรวจเองได้ทุกครั้ง

ถ้าคำถามไม่เกี่ยวกับข้อมูล (เช่น "ราคาทองวันนี้") โปรแกรมตอบว่าไม่เข้าใจ
ไม่เดาตัวเลขให้

## วิธีเปิดใช้ AI

**ตั้งค่าในแอปได้เลย** ไม่ต้องแก้ไฟล์ — เปิดแท็บ 💬 ถาม-ตอบ แล้วกด **⚙ ตั้งค่า AI**

1. เลือกโหมด — มี 5 ตัวเลือก เรียงจากปลอดภัยที่สุด:
   **ไม่ใช้ AI** · Ollama (ในเครื่อง) · Anthropic · OpenAI · Gemini
2. เลือกโมเดลจากรายการ (Ollama จะไปอ่านจากเครื่องจริงว่าลงอะไรไว้บ้าง)
   หรือกด **พิมพ์เอง** ถ้าใช้โมเดลอื่น
3. วาง API key แล้วกด **บันทึก** · กด **ทดสอบการเชื่อมต่อ** ดูว่าใช้ได้จริง

สลับกลับไปโหมด "ไม่ใช้ AI" ได้ทุกเมื่อ **กุญแจยังถูกเก็บไว้** จะได้ไม่ต้องกรอกใหม่
(อยากลบจริง ๆ กด "ลบกุญแจ")

### กุญแจถูกเก็บยังไง

- เขียนลง `ai.yaml` ข้าง `DentalDX.exe` — **ในเครื่องคุณเท่านั้น** ไม่ส่งไปไหน
- `ai.yaml` อยู่ใน `.gitignore` แล้ว จะไม่หลุดขึ้น GitHub
- **หน้าเว็บไม่เคยได้กุญแจตัวจริงกลับไป** เห็นแค่ `sk-ant…4f2a`
  (ช่องกรอกเว้นว่าง = ไม่เปลี่ยนของเดิม)
- เว็บเปิดที่ `127.0.0.1` เท่านั้น เครื่องอื่นในเครือข่ายเข้าไม่ได้

จะแก้ไฟล์เองก็ได้ (ดู `ai.yaml.example`) หรือใช้ environment variable ก็ได้:
`DENTALDX_AI_KEY`, `DENTALDX_AI_PROVIDER`, `DENTALDX_AI_MODEL`, `DENTALDX_AI_URL`
— ค่าจาก environment จะทับค่าในไฟล์ (หน้าตั้งค่าจะเตือนให้ถ้ามีตั้งไว้)

```yaml
provider: anthropic      # anthropic | openai | gemini | ollama | off
model: claude-haiku-4-5
api_key: "sk-ant-..."
phrase: true             # ให้ AI เรียบเรียงประโยคตอบด้วย
confirm: true            # โชว์ข้อมูลที่จะส่งแล้วรอกดยืนยัน
```

### เลือกผู้ให้บริการ

| provider | เหมาะกับ | ข้อควรรู้ |
|---|---|---|
| `anthropic` | ใช้งานทั่วไป | `claude-haiku-4-5` ถูกและเร็วพอ (~1-2 สตางค์/คำถาม) |
| `openai` | มีบัญชีอยู่แล้ว | `gpt-4o-mini` |
| `gemini` | มีกุญแจฟรีอยู่แล้ว | **free tier มีเงื่อนไขเรื่องข้อมูล — อ่านหัวข้อล่าง** |
| `ollama` | ห้ามต่อเน็ต | รันในเครื่อง ไม่มีค่าใช้จ่าย แต่ต้องลงโปรแกรมเพิ่มและช้ากว่า |
| `off` | ค่าเริ่มต้น | ใช้ตัวแปลคีย์เวิร์ด ไม่ต่อเน็ต |

### ⚠ ถ้าจะใช้ Gemini free tier

Google ระบุในเงื่อนไขของ Gemini API ว่า **prompt และคำตอบของบริการที่ไม่เสียเงิน
อาจถูกนำไปใช้พัฒนาผลิตภัณฑ์ และอาจมีคนเข้ามาอ่าน (human review)** และแนะนำเองว่า
อย่าส่งข้อมูลที่เป็นความลับหรือข้อมูลส่วนบุคคลเข้าบริการที่ไม่เสียเงิน
ส่วน paid tier จะไม่นำ prompt ไปเทรนโมเดล

DentalDX ไม่ส่งข้อมูลเด็กรายคนอยู่แล้วในทุกกรณี แต่ **ตัวเลขสรุประดับอำเภอ
ถือเป็นข้อมูลของหน่วยงาน** ไม่ใช่ของเรา ทางเลือก:

| ทางเลือก | สิ่งที่ส่งขึ้น cloud |
|---|---|
| Gemini free + `phrase: true` | คำถาม + ชื่อตาราง/ตัวชี้วัด + **ตัวเลขสรุป** |
| Gemini free + `phrase: false` | คำถาม + ชื่อตาราง/ตัวชี้วัด (**ไม่มีตัวเลขเลย**) |
| ผูกบัญชีเป็น paid tier | เหมือนกัน แต่ไม่ถูกนำไปเทรนโมเดล |
| `provider: ollama` | ไม่มีอะไรออกจากเครื่องเลย |

ถ้าจะใช้ฟรีจริง ๆ แนะนำ **`phrase: false`** — ตัวเลขจะไม่ออกจากเครื่อง
แลกกับคำตอบที่เป็นรูปแบบมาตรฐานแทนประโยคธรรมชาติ (ยังอ่านง่ายอยู่)

**ค่าใช้จ่าย** — prompt ที่ส่งไปเป็นแค่แคตตาล็อก ราว 1,500 token ต่อคำถาม
ถ้าตั้ง `phrase: false` จะเรียก AI ครั้งเดียวต่อคำถาม (ประหยัดครึ่งหนึ่ง)
แต่คำตอบจะเป็นรูปแบบมาตรฐานแทนประโยคธรรมชาติ

**เน็ตล่ม / กุญแจหมดอายุ** — โปรแกรมถอยไปใช้ตัวแปลคีย์เวิร์ดให้อัตโนมัติ
และบอกไว้ใต้คำตอบว่าเรียก AI ไม่สำเร็จ ไม่ขึ้นหน้าจอ error เปล่า ๆ

## ขอบเขตที่ตอบได้ตอนนี้

ตอบได้:

- ทุกตัวชี้วัดในทุกตารางของ profile YAML (เพิ่มตัวชี้วัดใน YAML แล้วถามได้ทันที
  ไม่ต้องแก้โค้ด)
- แยกตามอายุรายปี / ช่วงอายุ / รวม
- กรองตามจังหวัด อำเภอ หรือหน่วยบริการ
- เทียบรายอำเภอหรือรายหน่วยบริการ เรียงมาก→น้อย หรือน้อย→มาก

ยังตอบไม่ได้ (ถ้าอยากได้บอกได้):

- เทียบข้ามช่วงเวลา (ข้อมูลชุดปัจจุบันเป็นภาพนิ่งชุดเดียว)
- เทียบข้ามกลุ่มอายุในคำถามเดียว เช่น "0-5 ปี กับ 6-12 ปี ต่างกันแค่ไหน"
- ถามหารายชื่อเด็กรายคน — **ตั้งใจไม่ให้ทำ** เพราะเป็นข้อมูลผู้ป่วย
  (ยังคลิกดูรายชื่อจากตารางรายงานได้เหมือนเดิม ซึ่งอยู่ในเครื่องล้วน ๆ)

## ไฟล์ที่เกี่ยวข้อง

| ไฟล์ | หน้าที่ |
|---|---|
| `core/ask.py` | แคตตาล็อก · แปลคำถาม · คำนวณ · เรียบเรียงคำตอบ |
| `app.py` | `POST /api/ask` และ `GET /api/ask/status` |
| `templates/index.html` | แท็บ 💬 ถาม-ตอบ (`loadAsk`, `runAsk`, `renderAnswer`) |
| `ai.yaml.example` | ตัวอย่างไฟล์ตั้งค่า |
| `tools/smoke_test.py` | `check_ask()` — ตรวจตัวเลขตรง + ไม่มีข้อมูลหลุด |

### เพิ่มคำพ้องให้ตัวแปลคีย์เวิร์ด

ถ้าคนในหน่วยงานเรียกตัวชี้วัดด้วยคำอื่น เติมใน `ALIASES` ที่ `core/ask.py`:

```python
ALIASES = {
    "ปราศจากฟันผุ": ["caries free", "ฟันไม่ผุ", "ปลอดฟันผุ", "<คำใหม่>"],
}
```
