## แท็บถาม-ตอบทำงานอย่างไร (สรุปสั้น)

**AI แปลคำถาม — DentalDX คำนวณเอง** ข้อมูลเด็กไม่ออกจากเครื่อง

```
คำถาม + แคตตาล็อก(ชื่อตาราง/ตัวชี้วัด)  ─►  AI  ─►  JSON {"table":"2","metric":"ปราศจากฟันผุ","rows":["3"]}
                                                        │
                        core/ask.py คำนวณเองด้วย engine ชุดเดียวกับตารางรายงาน
                                                        │
                        ตัวเลขสรุปอย่างเดียว  ─►  AI  ─►  ประโยคภาษาไทย
```

รายละเอียดครบอยู่ที่ **`docs/ถาม-ตอบด้วย-AI.md`**

**หน้าตั้งค่าในแอป** (ปุ่ม ⚙ ในแท็บถาม-ตอบ) — สลับโหมดใช้/ไม่ใช้ AI, เลือก
provider (off / ollama / anthropic / openai / gemini), เลือกโมเดล (ollama ดึงรายชื่อ
จากเครื่องจริงผ่าน `/api/tags`), ใส่ API key, ปุ่มทดสอบการเชื่อมต่อ
กุญแจเขียนลง `ai.yaml` ในเครื่อง **ไม่เคยส่งกลับไปหน้าเว็บ** (เห็นแค่ `sk-ant…4f2a`)

ไฟล์ที่แตะในรอบนี้: `core/ask.py` (ใหม่) · `app.py` (+ 9 endpoint ใต้ `/api/ask`)
· `templates/index.html` (+แท็บ +กล่องยืนยัน +หน้าตั้งค่า)
· `tools/smoke_test.py` (+`check_ask`) · `ai.yaml.example` (ใหม่)
· `.gitignore` (+`ai.yaml`)

## ค่าตั้งใน profile YAML (แก้ได้เองไม่ต้อง build ใหม่)

```yaml
age_clamp: both          # max | min | both — ปรับอายุที่หลุดช่วงแทนการตัดออก
bands:
  - {label: "3-5", min: 3, max: 5, split: true}   # แตกแถวย่อยรายอายุ
metrics:
  - name: "ฟันผุไม่ได้รักษา"
    expr: "dcaries > 0"
    followup: true       # ช่องนี้คลิกดูรายชื่อเด็กได้
```

> เพิ่มตัวชี้วัดใน YAML แล้ว **ถามในแท็บถาม-ตอบได้ทันที** ไม่ต้องแก้โค้ด
> เพราะแคตตาล็อกที่ส่งให้ AI สร้างจาก YAML โดยตรง

## ข้อควรระวังที่เคยเจอมาแล้ว (อย่าพลาดซ้ำ)

- ไฟล์ `.bat` ต้องเป็น **ASCII ล้วน + CRLF** ห้ามใส่ภาษาไทยหรือ `chcp 65001`
- `apply_scope` ต้อง `.copy()` ก่อนแก้ mask ไม่งั้นเขียนทับข้อมูลต้นทาง
- pandas เปลี่ยน `None` เป็น `NaN` (truthy) เมื่อคอลัมน์เป็น float → ใช้ numpy array แทน
- `to_numpy(dtype=bool)` กับคอลัมน์ Int64 ที่มีค่าว่างจะ error ต้อง `.fillna(False)` ก่อน
- JSON ห้ามมี `NaN` (Python ยอม แต่เบราว์เซอร์ไม่ยอม) — มี `NanSafeJSON` ใน `app.py` แล้ว
- Flask cache template แม้ `debug=False` → ตั้ง `TEMPLATES_AUTO_RELOAD` + `jinja_env.cache = None`
- ห้าม commit ข้อมูลผู้ป่วย (`data/**`, `*.xlsx`) — `.gitignore` กันไว้แล้ว
- **ห้าม commit `ai.yaml`** (มี api_key) — `.gitignore` กันไว้แล้ว ตัวอย่างอยู่ที่ `ai.yaml.example`
- ตารางคุณภาพ (kind: quality) ใช้ "จำนวนที่ตรวจ" เป็นตัวหาร ไม่ใช่ `quality_mask`
  ไม่งั้นร้อยละผ่านเกณฑ์จะเป็น 100% เสมอ (เคยพลาดตอนเขียน `ask._denominator`)
- ชื่ออำเภอกับชื่อโรงพยาบาลมักซ้ำกัน ("เกษตรสมบูรณ์") — `ask.resolve_area`
  ตัดสินจากคำนำหน้าที่ผู้ใช้พิมพ์ ("อำเภอ" vs "โรงพยาบาล")
- แปลงเลขไทยตัวหนังสือเฉพาะที่ตามด้วย "ขวบ/ปี" เท่านั้น ไม่งั้น "สามารถ"
  จะกลายเป็น "3ารถ" (มีเทสต์กันไว้แล้ว)
- `ask.config()` ต้องอ่านจาก `config_path()` ให้ตรงกับที่ `save_config()` เขียน
  ไม่งั้นบันทึกผ่านหน้าเว็บแล้วโปรแกรมไม่เห็นค่าใหม่ (เคยพลาดมาแล้ว)
- `ai_enabled()` ไม่ไปแก้ค่า `provider` ทิ้งเวลาไม่มีกุญแจ ไม่งั้นหน้าตั้งค่า
  จะลืมสิ่งที่ผู้ใช้เลือกไว้
- `reference/*.csv` ตั้ง `-text` ใน `.gitattributes` ถ้าเห็นว่าถูกแก้ทั้งไฟล์
  แปลว่าโดนแปลง CRLF/LF สั่ง `git checkout -- reference`
  (ถ้าติด `.git\index.lock` ให้ `Remove-Item .git\index.lock` ก่อน)
